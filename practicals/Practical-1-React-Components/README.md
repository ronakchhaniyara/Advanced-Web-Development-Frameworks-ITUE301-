# Practical 1: Introduction to React and Component Architecture

## Objective

To set up a React development environment using Vite and build a static
student portfolio UI using independently structured and reusable React components.

---

## Problem Statement

Create a React-based student portfolio page using reusable functional components.

The application should contain at least four components:

- Header
- About
- Skills
- Footer

Props should be used to pass data from the parent component to child components.

---

# Practical 2: State Management and Routing in React

## Objective

To extend the React portfolio application created in Practical 1 by
implementing state management using `useState` and client-side navigation
using React Router.

---

## Problem Statement

Extend the existing portfolio application by adding React Router and
state management.

The application should contain at least three routes:

- Home
- Projects
- Contact

The Contact page should contain a controlled input whose value is managed
using `useState`.
